# Skill Authoring Workflow

Use when creating or optimizing a skill. This file covers source selection and approval; the caller's available authoring tools supply format mechanics.

1. Read the active runtime's skill format and authoring guidance.
2. Read relevant local sources: installed skills, resources, and problem memory when behavior-driven.
3. For a new skill, research relevant external candidates; for an existing skill, search externally only when local coverage is insufficient or the user requests it.
4. Choose disposition by expected execution value: reuse installed skill, adopt whole external skill, mix fragments/ideas, or create/update custom skill.
5. Check compatibility with hard constraints, existing naming/location conventions, and source-backed requirements.
6. Present source findings, conflicts, disposition, and design for approval before editing.
7. After approval, use the active runtime's authoring tools; keep this workflow focused on source selection and local constraints.
8. Verify local paths, line counts, invocation behavior, and the required format.
